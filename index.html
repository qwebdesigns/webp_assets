Откройте Unity AssetBundle

Перетащите файл в окно, выберите его кнопкой «Файл…» или нажмите на бандл из списка выше. Всё разбирается локально: ни один байт не уходит на сервер.

Как это работает

UnityFS под чужим именем

Файлы вида itemicons.webp — это не картинки WebP. Внутри лежит обычный Unity AssetBundle (сигнатура UnityFS), а расширение и Content-Type: image/webp нужны только для отдачи через nginx.

Полностью в браузере

Бандл скачивается в память страницы, распаковывается и декодируется WebAssembly-модулем. Текстуры DXT/BC/ETC/ASTC/Crunch превращаются в PNG, звуки — в проигрываемые файлы. Сервер нужен только чтобы отдать статические файлы.

Свои бандлы на GitHub Pages

Положите файлы в public/bundles/ и задеплойте сайт. Список можно задать в bundles/bundles.json, иначе просмотрщик проверит известные имена игры. Чужие домены без CORS открыть нельзя — скачайте файл и перетащите его в окно.
