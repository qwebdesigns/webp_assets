# Bundle Viewer (Python, legacy)

> **Это старая версия.** Основной просмотрщик теперь статический и работает без Python —
> см. [README в корне репозитория](../../README.md). Этот вариант оставлен для случаев,
> когда нужен локальный сервер, читающий чужие бандлы без CORS.

Локальный веб-просмотрщик Unity AssetBundle, который читает бандлы **прямо по ссылке**
(или из локального файла / drag & drop) и показывает содержимое в браузере.

Бандл скачивается в оперативную память, парсится [UnityPy](https://github.com/K0lb3/UnityPy)
и никуда не сохраняется: на диске не появляется ни `.bundle`, ни временных файлов.

## Зачем

Файлы вида `https://blockade3d.com/ClassicBundles/itemicons.webp` — это не WebP-картинки.
Расширение `.webp` и `Content-Type: image/webp` нужны только для отдачи через nginx,
а внутри лежит обычный **UnityFS** (сигнатура `UnityFS`, Unity 6000.3.x).
В браузере их грузит сама игра через `UnityWebRequest`, поэтому CORS ей не мешает.

Обычный путь «скачать → открыть AssetStudio» работает, но каждый раз требует файла на диске.
Этот просмотрщик делает то же самое по одной ссылке.

## Установка

```powershell
python -m pip install -r requirements.txt
```

## Запуск

```powershell
python viewer.py
```

Или двойной клик по `run.bat` (то же самое, но сразу открывает браузер).

Откройте <http://127.0.0.1:8765/> — по умолчанию сразу загрузится `itemicons`.

Полезные ключи:

```powershell
python viewer.py --port 9000            # другой порт
python viewer.py --open                 # сразу открыть браузер
python viewer.py --default-src "https://.../ui.webp"
python viewer.py --host 0.0.0.0         # доступ из локальной сети
python viewer.py --verbose              # логировать запросы
```

## Как пользоваться

1. **Ссылка на бандл** — вставьте URL и нажмите «Открыть» (или Enter).
2. **Папка версии** — вставьте базовый URL вида
   `https://blockade3d.com/ClassicBundles/` и нажмите «Найти бандлы».
   Сервер проверит все известные имена (`itemicons`, `ui`, `hud`, `atlases`, `sounds`, …)
   и покажет чипсы только с теми, что реально есть в этой версии игры. Клик по чипсу — загрузка.
3. **Файл…** или перетаскивание файла в окно — разбор локального бандла без копирования на диск.
4. Поиск по имени, фильтр по типу, сортировка, размер превью.
5. Клик по карточке — полноразмерный просмотр (стрелки ←/→ листают, Esc закрывает).
6. **ZIP** — выгрузить все картинки/звуки/тексты бандла одним архивом (собирается в памяти, лимит 512 МБ).

## Что умеет показывать

| Тип | Превью |
| --- | --- |
| `Texture2D` | PNG, декодирование DXT1/3/5, BC4/5/6/7, ASTC, ETC, PVRTC, crunch-варианты |
| `Sprite` | PNG (через связанную текстуру) |
| `AudioClip` | проигрывание и скачивание (m4a/wav/ogg, как в бандле) |
| `TextAsset` | текст в окне |
| остальное | метаданные + скачивание сырых сериализованных байтов |

В бандлах BLOCKADE сейчас встречаются только `Texture2D`, `AudioClip`, `ComputeShader`
и `AssetBundleManifest`; остальное поддерживается на случай других версий/игр.

Альфа-канал показывается на шахматном фоне.

## Почему нужен локальный сервер, а не просто HTML-страница

`blockade3d.com` не отдаёт `Access-Control-Allow-Origin`, поэтому `fetch()` со страницы
на другом origin не смог бы прочитать бандл. Здесь страницу обслуживает тот же локальный
сервер, который и скачивает бандл, так что CORS не мешает.

## API (если нужна автоматизация)

| Endpoint | Параметры | Что делает |
| --- | --- | --- |
| `GET /api/list` | `src`, `refresh=1` | JSON со списком объектов бандла |
| `GET /api/asset` | `src`, `pid`, `mode=thumb\|full\|raw`, `w`, `dl=1` | картинка/звук/текст/сырые байты |
| `GET /api/export` | `src` | ZIP со всеми превью |
| `GET /api/probe` | `base`, `names=a,b,c` | проверка, какие бандлы есть в папке |
| `POST /api/upload` | тело = файл, `X-Filename` | разбор загруженного файла |
| `GET /api/config` | — | настройки UI по умолчанию |

`pid` — это `path_id` объекта (int64), в JSON он отдаётся **строкой**, чтобы не терять
точность в JavaScript.

Пример:

```powershell
python -c "import requests,json; j=requests.get('http://127.0.0.1:8765/api/list',params={'src':'https://blockade3d.com/ClassicBundles/itemicons.webp'}).json(); print(j['total'], j['assets'][0])"
```

## Как это работает

- `requests` качает бандл в память (с обычным User-Agent).
- `UnityPy.load(bytes)` разбирает UnityFS, включая LZ4/LZMA-сжатие и сериализованные файлы.
- Список объектов и превью кэшируются в памяти (до 768 МБ, 8 бандлов, LRU).
- Превью генерируются лениво и тоже кэшируются.
- Сервер слушает только `127.0.0.1` и проверяет заголовок `Host` (защита от DNS-rebinding).

## Ограничения

- `Texture2D`, у которых формат не поддерживается декодером, покажут «⚠»; сырые байты всё равно доступны.
- `Sprite` из бандла, который ссылается на текстуру в **другом** бандле, может не отрисоваться:
  нужна зависимость из `*.manifest` (пока не подгружается автоматически).
- ZIP собирается в памяти — для `zoomtextures` (633 крупных текстуры) это долго и может упереться в лимит.
- Просмотрщик не заменяет AssetStudio для мешей/анимаций/шрифтов, но для иконок, UI и звуков удобнее.
